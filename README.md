# 微信美化 · WeChat Beautify

Windows 微信主题工作室：自定义背景、图片裁剪、分区配色与文字可读性检查。当前版本 **0.4.0（实验版）**。

Windows 微信主题控制器，提供自定义背景图和系统毛玻璃两种模式。图片模式已在本机微信主窗口看到背景；系统毛玻璃内部透明效果仍需验证。

0.4 更名为「微信美化」，新增分区配色编辑器、深浅色独立保存、HEX 输入和颜色选择器、区域不透明度、点击预览编辑以及自定义配色可读性检查。

控制器使用 .NET 10 Desktop Runtime。构建后请保留同目录 DLL、deps.json、runtimeconfig.json 和 native-runtime 文件夹，推荐双击 `dist/微信美化.lnk`（直接使用 .NET 官方宿主）。开发环境的独立 EXE 曾无法枚举全部进程，原因尚未确认，完整手动主题启动仍需实机验证。

## 分区配色

在「03 对话配色」点击「分区自定义颜色…」，或直接点击右侧预览区域。导航栏、会话列表、聊天消息区域、输入区域、选中行、发送气泡、接收气泡、文字和图标支持独立选色。区域背景用不透明度控制：0% 保留背景，100% 纯色覆盖。搜索区沿用会话列表颜色。

消息正文和消息链接由双方共用；发送与接收气泡底色独立。选择「编辑深色方案」可编辑另一套颜色，主界面的深浅色开关选择当前应用的方案。恢复此项只影响当前深浅色；取消不保存，保存后点击「更新主题」应用。

可读性检查使用自定义颜色和分区蒙版，气泡或链接对比不足时不会误推荐整体遮罩。本次原生引擎有更新，已加载旧模块的微信需要从托盘退出再启动。全界面透明效果和本次分区绘制尚需实机确认。

## 自定义背景

1. 双击 `微信美化.lnk`，点击左上角「选择图片…」。支持 PNG、JPG、JPEG、BMP，最大 40 MB / 3200 万像素。
2. 调节「图片模糊」和「明暗遮罩」；「深色主题」使用暗色遮罩，浅色使用亮色遮罩。图片会居中裁切铺满。
3. 本地副本保存在程序旁 `data/backgrounds`，处理后的图在 `data/effects`。不会改动原图，也不会上传图片。设置自动保存。
4. 「清除背景」撤销图片选择，切回系统毛玻璃模式；清除选择不会删除原图。修改后点击「更新主题」才更新微信。

## 启动与连接

- 首次启用：从微信托盘菜单完全退出微信 → 在本程序点「启动主题微信」→ 正常登录 → 点击「更新主题」。不要再点击普通开始菜单或桌面微信入口。
- 顶部区分「微信未运行」「普通微信正在运行 · 未加载主题」「主题模块已加载」。模块加载和回执正常表示配置被接收；视觉效果还需要查看微信。
- 微信已运行时不会强制关闭，也不会重复加载主题。启动后会等待并验证模块，不再把单纯启动请求当作主题加载成功。
- 支持微信 4.1.15.56 x64，完整 Weixin.dll SHA-256 必须匹配。微信升级后不能跳过检查。

## 恢复与限制

点击「恢复默认」停用本次主题。完全卸载进程内模块需从托盘退出微信，再用原来的微信入口启动。程序不修改微信安装文件、不创建开机自启。关闭控制器不会移除正在使用的主题。

图片模式使用微信原生绘制引擎加载图片。系统毛玻璃模式尝试启用 Qt 透明背景及 Windows Acrylic；尚未完成整个微信界面的透明效果验证。窗口外框有材质、接口成功或控制器预览不能证明整个微信已变成毛玻璃。

程序需对自身目录有写权限。data 存放设置、图片和快照；旧快照保留用于回退。恢复不依赖原图存在。诊断不包含聊天内容，但包含本机路径。

## 构建与检查

运行环境：Windows 10/11 x64、.NET 10 Desktop Runtime。
构建环境：.NET 10 SDK、Node.js、Visual Studio C++ x64 工具和 Windows SDK；无第三方 NuGet 包。

```powershell
git clone https://github.com/dddedd51/WeChat-Beautify.git
cd WeChat-Beautify

# 获取固定提交的上游构建输入，并校验 SHA-256。
.\fetch-upstream.ps1

# 编译原生模块、控制器并生成本地启动快捷方式。
.\build.ps1

# 隔离自检，不操作微信。
.\test.ps1
```

依赖下载：[.NET 10 SDK / Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)、[Node.js](https://nodejs.org/)、[Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)（安装「使用 C++ 的桌面开发」和 Windows SDK）。没有第三方 NuGet 包依赖。

构建完成后打开 `dist/微信美化.lnk`，或者运行：

```powershell
dotnet .\dist\微信美化.dll
```

快捷方式包含本地绝对路径，移动项目后重新构建即可生成。已有原生构建产物时，仅编译控制器可使用 `.\build.ps1 -ControllerOnly`。

上游源码下载至 `research/reference/Windows-WeChat-Theme-Studio-37d8188502ed4365ddcde928c7b2e50fda5e7226`，不纳入版本控制。脚本从源码生成并编译带扩展的 DLL，不运行用户 ZIP 内原程序。本仓库不附带微信安装文件或预编译主题包。

隔离测试验证图片导入、裁剪、像素模糊、明暗处理、分区配色与透明度、深浅方案、设置持久化、对比度、模式切换、恢复和文件校验，并渲染控制器；测试不操作微信，通过测试不等于通过实机视觉验证。来源与再分发限制见 [THIRD-PARTY.md](THIRD-PARTY.md)。

## 0.3 新增：裁剪与可读性

- 「选择图片」后进入裁剪窗口；已有图片可点「裁剪与定位」。拖动选框移动，滚轮或滑杆缩放；按住 Shift 拖出新选框，可锁定自由、当前预览、16:9、4:3、1:1 比例。取消不更改已保存的构图。
- 裁剪使用原图副本，保存归一化坐标；不破坏原图，也不会反复裁切导致损失。导出给微信的图片与预览使用同一裁剪。
- 当前预览使用固定示意布局；微信与预览窗口比例不同仍会中心裁切铺满，可重新裁剪调整构图。
- 可读性检查使用裁剪、模糊后的图片进行 64×64 网格采样，对照主题主文字、次文字与固定气泡、选中项颜色，参考普通文字 4.5:1 对比度。
- 「采用建议遮罩」仅调整本地方案，重新检查后点击「更新主题」应用到微信。只在采样全部达到阈值时显示通过；细小图案、实际消息位置、图片内容和渲染抗锯齿未纳入检查，不能当作完整无障碍认证。
- 启动方式增加明确的 -testability 参数，并使用主题运行目录作为工作目录。本机已验证此方式加载模块，并在微信主窗口实际看到自定义背景。
