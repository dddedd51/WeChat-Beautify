# 微信美化 · 青屿

为 Windows 微信换上自己的颜色。**0.5 预览版**带来重做的浅色客户端、`#39C5BB` 青屿主题、内置使用指南与自研原生绘制引擎。

[下载预览版与校验文件](https://github.com/dddedd51/WeChat-Beautify/releases) · [来源与参考项目](THIRD-PARTY.md)

> **使用前请注意：这是非官方、实验性的运行时美化工具，不保证不封号。** 加载第三方模块、改变微信内部绘制可能带来兼容性、崩溃或账号限制风险。请先阅读下方「实现原理」和「账号风险：不保证不封号」；不能接受账号风险时，请勿使用。

## 现在能做什么

- **青屿主题**：青绿色选中项、柔和背景、独立的深浅配色。一键选择后点击「更新主题」。
- **自定义背景**：本地导入 PNG/JPG/BMP，框选裁剪、移动、缩放、锁定比例，调节模糊和明暗遮罩。
- **分区配色**：导航、会话列表、聊天背景、输入背景、选中会话、列表名称、摘要和选中文字。HEX 输入与颜色选择器可配合使用。
- **可读性检查**：估算列表名称、摘要及选中项对比度，必要时提供遮罩建议。
- **内置教程**：左侧「使用指南」包含启动、裁剪、应用、恢复与常见问题。
- **恢复默认**：停用本客户端主题，保留微信安装文件和个人图片。

消息气泡、消息正文、链接与图标当前保留微信原样；编辑器中尚未支持的项目置灰。深色背景下仍需检查原生内容的可读性。当前提供背景模糊与分区半透明叠色，**尚未实现实时透出桌面的整窗毛玻璃**。

## 实现原理

本工具在微信运行过程中调整界面绘制，流程如下：

1. **启动时加载模块**：客户端通过 Qt 的 `testability` 加载入口，让微信载入本项目的 `qttestability.dll`，校验目标 Weixin.dll 后加载自研 `beautify-engine.dll`。
2. **接管已适配控件的绘制回调**：引擎修改进程内已核对的共享虚表槽，在文字绘制之前画入背景图片和分区颜色，再由微信原生函数绘制文字。对已支持的列表文字，绘制时临时设置颜色，随后恢复。这样避免了在最终画面上改像素造成的文字白底问题。
3. **本地处理与刷新**：图片裁剪、模糊和明暗遮罩在本机完成；引擎读取更新后的配置并刷新界面。带请求号和进程号的回执用于确认配置应用，不能替代实际画面检查。
4. **停用与退出**：「恢复默认」停用主题绘制；从托盘完全退出微信后，模块和进程内改动随进程消失。下次从原微信入口启动，不加载本工具的主题模块。

**不修改微信安装文件，不等于没有修改微信运行状态。** 本工具会加载第三方 DLL，改变进程内部分绘制函数指向和文字颜色状态。当前实现没有主动读取或导出聊天记录、修改通信协议或自动收发消息的功能，但这些设计限制不代表不会被检测或限制账号。

当前效果是图片模糊与分区半透明叠色，尚未实现实时透出桌面的毛玻璃。更详细的实现与验证边界见 [引擎设计](native/independent/DESIGN.md) 和 [研究记录](native/independent/RESEARCH.md)。

## 使用方法

1. 安装 [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0)。使用本机微信 **4.1.15.56 x64**；程序还会校验完整 Weixin.dll 哈希。
2. 将发布 ZIP 完整解压到普通下载目录中的新文件夹，双击 `微信美化.exe`。保留同目录依赖与 `native-runtime` 文件夹；不要只拿走 EXE。
3. 在「主题空间」选择青屿，或到「背景与构图」选择图片。裁剪窗口拖动选框移动，滚轮缩放，按住 Shift 拖出新选框。
4. 首次启用时，从微信托盘菜单完全退出微信，然后点本客户端的「启动主题微信」，自行完成登录。
5. 进入聊天主窗口后，修改选项并点击「更新主题」。顶部显示连接状态，底部显示本次请求的结果。
6. 需要还原时点击「恢复默认」。从托盘退出微信后，引擎随进程卸载；使用原微信入口启动就是普通微信。

选图、裁剪和颜色只改变本地方案；「更新主题」才应用到微信。普通微信入口不会加载主题。微信已运行时客户端不会强制关闭它。

图片和配置保存在程序旁的 `data`，不会上传。裁剪保留原图副本，取消编辑不覆盖方案。移动整个程序后，旧设置里的绝对图片路径可能需要重新选择。

## 构建

Windows x64、.NET 10 SDK、Visual Studio C++ x64 Build Tools、Windows SDK。当前默认构建**不再下载或编译旧上游引擎**，也不需要 Node.js、Ghidra 或 Frida。

```powershell
git clone https://github.com/dddedd51/WeChat-Beautify.git
cd WeChat-Beautify
.\build.ps1
.\test.ps1
```

输出在 `dist/`。完整构建生成入口 `qttestability.dll` 和 `beautify-engine.dll`，控制器校验两个文件。引擎按哈希存放在独立运行目录，防止新版文件与已加载旧模块混用。配置通过带唯一请求号的 UTF-16 文件传递；回执匹配请求号和进程，避免旧回执误报成功。

## 实测与限制

自研引擎在微信绘制文字之前替换已识别的控件背景，文字继续由原生绘制。已在本机观察到会话行背景、无白底的原生文字、青绿选中项、窗口缩放、滚动、配置更新、停用恢复及同进程引擎重启。客户端与正在运行的测试微信已完成连接和更新回执检查。

便携 ZIP 已在普通下载目录中解压验证：客户端以普通权限（Medium）运行，由用户点击启动按钮，完成登录后显示自定义背景、青绿选中项和原生文字；收到匹配 pid/revision 的 applied 回执。更新图片与停用恢复回执已核对。

开发目录曾继承低完整性标记，导致 EXE 普通双击后仍受限。干净 ZIP 解压到新目录后已解决，无需管理员权限。若出现低完整性提示，请重新解压到普通文件夹；若此前以管理员身份运行过微信，请先从托盘退出，再用普通权限客户端启动。客户端不会自动提权或修改安全设置。

不同 DPI、多显示器、休眠和长期运行未完成覆盖；其他页面逐步适配。编译和离线自检不等于所有实际页面都已验证。因此当前为预览版，尚不作为稳定完整 Release。

可读性结果来自整图 64×64 采样，不读取聊天内容，也不代表实际文字位置或完整无障碍认证。诊断不记录聊天，但含本机路径。

- `src/`：客户端、教程、裁剪、配色、青屿背景生成和对比度检查。
