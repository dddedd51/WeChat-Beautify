# 自研原生绘制引擎

0.5 默认构建采用 `engine-entry.c` 与 `semantic-engine.cpp`。不再构建、下载或回退到旧上游引擎。Qt 绘制接口按微信 4.1.15.56 x64 的完整 Weixin.dll SHA-256 限定；未知版本拒绝加载。

## 绘制顺序

原型曾尝试在 DXGI 最终画面上替换底色，实测无法可靠区分文字空洞、边缘和灰色图像，留下文字白底。`dxgi-probe.cpp`、`compositor.h` 和相应测试仅保留为历史实验，不进入默认构建。

当前引擎在经过核对的控件背景接口绘制图片与分区叠色，然后由原生文字接口绘制文字。会话行使用独立的已验证父链；坐标计算支持高于窗口的滚动内容，并映射到外层 MainView。原生文字颜色临时替换后立即恢复，段落缓存失效使用 notify=false，避免每帧通知导致持续重绘。

共享虚表槽在安装前核对原函数，安装失败回滚。回调表只构建一次，安装期间保持不可变。指针范围检查和 C++ 异常处理不能保证未知 ABI 安全；C++ catch 不是 Windows 访问异常保护。

## 生命周期与配置

入口在 `qt_testability_init` 运行，校验安装文件后加载同目录适配器；DllMain 不执行绘制接入。客户端按双 DLL 哈希建立运行目录。

GUI 线程计时器读取原子替换的 UTF-16 `theme.ini`，读取间隔至少 500 ms。图片在 GUI 线程解码、更换引用并释放旧引用。配置携带唯一 revision；UTF-8 回执同时包含 revision、pid、state、wallLoaded。applied 表示读取配置并进入有效绘制回调，不证明所有区域视觉正确。

停用恢复原生绘制；`semantic_stop` 仅接受 GUI 线程且不能在 paint 内调用，会停止计时器、恢复槽和释放图片。DLL 留在进程中，直到微信退出；不在运行中执行 FreeLibrary。客户端「恢复默认」停用主题，普通微信入口下次启动不加载引擎。

## 验证范围

本机已观察到列表与聊天背景、无旧像素方案白底的原生文字、选中项与列表文字配色、滚动和窗口缩放、更新图片、停用恢复、同进程 stop/start。普通启动链路的状态以 README 的最新验证记录为准。离线测试覆盖滚动几何、父链与区域策略、配置序列化、裁剪和对比度计算。

消息气泡、正文、链接、图标和实时桌面毛玻璃尚未接入。泛型控件父链仍需更多页面验证；其他 DPI、多显示器、休眠和长时间运行未完成覆盖。

## 来源

接口事实通过安装的微信文件静态检查和 REA 运行证据核对，见 RESEARCH.md。旧本地混合引擎曾被反编译以研究背景与文字的先后关系；没有移植其对象表、delegate 克隆或像素算法。此前已阅读上游代码，不能声称法律意义上的 clean-room 实现。历史上游代码不打包，详见仓库 THIRD-PARTY.md。
